# PMO Governance & Software Delivery Toolkit
**Frameworks for High-Velocity Technical Program Management**

This repository contains standardized templates and frameworks I utilize to ensure 
100% project transparency, scope control, and engineering reliability.

### 🧰 Included Frameworks:
1. **Project Charter:** Defining the "North Star" and success metrics.
2. **RAID Log:** Centralized Risk, Action, Issue, and Dependency tracking.
3. **RACI Matrix:** Clear accountability for cross-functional teams.
4. **Reliability Metrics (MTTR/MTTF):** Data-driven engineering health.
5. **Fishbone (Ishikawa):** Deep-dive Root Cause Analysis (RCA).
6. **Stakeholder Matrix:** Influence vs. Interest mapping.
7. **Lessons Learned:** Continuous improvement for future sprints.
