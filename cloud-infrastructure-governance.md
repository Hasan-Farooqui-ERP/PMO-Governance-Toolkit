## ☁️ Cloud Infrastructure & Resource Governance (AWS)

### 🛠️ Technical Capabilities:
* **Compute:** Provisioning and managing **EC2 Virtual Servers**.
* **Traffic Management:** Configuring **Elastic Load Balancing (ELB)** to ensure system resilience and high availability.
* **Storage:** Managing **S3 Bucket** permissions and lifecycle policies.
* **Scaling:** Implementing **Auto-scaling** logic to align resource usage with real-time demand.

### 📉 Cost & Performance Governance
I apply the **8/80 Rule** to Cloud Infrastructure:
* **Micro-optimizations (< 8 hours):** Standard DevOps maintenance.
* **Architectural Shifts (> 80 hours):** Moving from monolithic instances to a load-balanced, distributed architecture requires a dedicated project phase to protect the P&L.
