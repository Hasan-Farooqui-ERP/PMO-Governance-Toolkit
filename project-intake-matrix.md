# 📥 Project Intake & Prioritization Matrix

This framework is used to evaluate new project requests before they enter the active portfolio.

### ⚖️ Scoring Logic (1-5 Scale)
* **Strategic Value:** How well does this align with the 2026 Digital Transformation roadmap?
* **Technical Complexity:** (1 = Simple API, 5 = Greenfield ERP/Migration).
* **ROI / Cost Savings:** Estimated FinOps optimization or revenue generation.

### 🚦 The 8/80 Intake Filter
* **Type A (Minor):** < 8 hours (Handled via BAU/Support).
* **Type B (Standard):** 8-80 hours (Requires Project Charter).
* **Type C (Enterprise):** > 80 hours (Requires SteerCo Approval & P&L Analysis).
